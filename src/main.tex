\begin{enumerate}
    \item What is a \textit{global} characterization of differentiability? Do differentiable functions have any algebraic or discrete invariants? I'm tired of using the bones and stick definition of differentiability and need something better. For instance, one could envision a situation where a function has an associated invariant (sth like a homotopy group for top. spaces) and the number of singular points of this function is the same as the number of holes of this invariant or something like that.
    \begin{itemize}
    
    \item For example, a function $f: \rr \to \rr$ given by $f(x) = |x|$ has a corner at $x = 0$ whereas the function $f(x) = x^2$ doesn't. How can you capture this \textit{corner}?

    \item In analysis we have the $\epsilon - \delta$ definition of continuity, which is a mess and there's a topological one, which is much cleaner. What is an idea that cleans up this notion of differentiability?

    \item (Fiction) Devise a process of \textit{melting} a function, whereby all the smooth points will turn into liquid and all the singular points will remain hard as a rock. That's how you can tell if the function is differentiable or not: melt it and see if any rocks remain at the bottom. It goes without saying that the process of melting should be a relatively easy one, so that we can quickly check if a function is differentiable or not. It seems like points should be assigned with \textit{weights.} Singular points are heavy whereas the smooth points are light. Question: what does it mean to \textit{melt} a function?
    \end{itemize}

\item Two non-homeomorphic topological spaces can have the same homotopy groups. What exactly is it about topological spaces that homotopy groups don't capture? Let's say that certain information $X$ is not captured by the homotopy groups. Can you devise another invariant of the topological space that does capture this information $X?$

\item Investigate where the hell this weird notion of $topological$ $space$ came from. Of course, it all started with Riemann's dissertation, which must be carefully read. Did Riemann perhaps envision a different notion? 

\item Let $f: E \to F$ be a linear map of two normed vector spaces over the same field. Does $f$ have to be continuous?
\begin{enumerate}
    \item Linearity of $f$ just means that triangles will be sent to triangles, and if you stretch the first triangle by $\lambda,$ then the image of this triangle will also be stretched by $\lambda.$ Question: what about $infinitly$ small triangles? Riemann mentions in his dissertation that a complex differentiable function sends infinitely small triangles to infinitely small triangles. What the hell is even an infinitely small triangle?
    \item Let $x$ and $y$ be two points in $E,$ and let $A$ be the triangle formed by $x, y, x+y.$
\end{enumerate}
\end{enumerate}
